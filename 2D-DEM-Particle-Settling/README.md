# 二维离散元颗粒群：隔板瞬时移除后的释放、碰撞与重力沉降

## 这是一个什么实验？

30 个近似等半径圆形颗粒先在**水平隔板上真实地沉降到基本静止**，然后在 `t=0` 让隔板瞬时消失。颗粒继续在重力作用下下落，碰撞底部及其他颗粒，最终重新堆积。以隔板高度 `0.10 m`、`0.15 m` 和 `0.20 m` 作为三个对照工况。三个工况使用**同一预先沉降好的颗粒构型**，只改变它离地面的高度。

这与“把30个球随机放在半空中直接释放”不同：释放之前，颗粒已经形成稳定堆积，并经受隔板法向支撑。

**重要边界：这是瞬时撤板，不是真正让隔板慢慢向右抽出。** 因此不模拟抽板速度、抽板期间的摩擦和拖曳。颗粒、墙和隔板之间均不考虑切向摩擦与转动，计算的是基础法向弹簧-阻尼接触的教学模型。

## Windows + VS Code 使用方法

从 ZIP 解压整个 `dem_shelf_release` 文件夹，使用 VS Code 的“文件 → 打开文件夹”打开它。终端输入：

```powershell
python -m pip install numpy numba matplotlib pillow
python shelf_release.py --output shelf_results
```

也可以在文件夹中双击 `run_windows.bat`。

如果你之前运行过 `dem_particles.py`，则安装环境通常已具备。本次**无需 MATLAB、DDA、YADE 或 ParaView**。

只运行基础力学与隔板平衡测试：

```powershell
python shelf_release.py --test-only
```

跳过 GIF（便于修改算法后快速复查）：

```powershell
python shelf_release.py --output test_result --no-gif
```

GIF 可以直接用 Windows 的 Edge 或 Chrome 打开；`shelf_results/shelf_release.gif` 也可以从文件资源管理器双击打开。动画开始的几帧展示隔板**支撑稳定颗粒**，然后隔板瞬时消失。移除后用于标识原高度的虚线**不是仍然存在的墙**。

## 主要参数在哪里改？

`shelf_release.py` 文件顶部：

```python
HEIGHTS = (0.10, 0.15, 0.20)  # 三组隔板高度（m）
DURATION = 3.2                # 撤板后的仿真时间（s）
PREPARE_DURATION = 3.0        # 隔板上预先稳定的时间（s）
PREPARE_ZETA = 0.70           # 初始化阶段的阻尼比
RELEASE_ZETA = 0.35           # 正式比较时的碰撞阻尼比
```

`dem_particles.py` 文件顶部有重力加速度、颗粒密度、法向接触刚度和容器宽度等参数（`GRAVITY, DENSITY, STIFFNESS, WIDTH`）。时间步长默认 `2e-5 s`；修改刚度或粒径后，需再次做数值稳定和接触重叠检查。不要同时修改多个自变量。

## 模型与计算方法

颗粒服从牛顿第二定律；接触发生在两球中心距小于半径之和时。法向接触力（压缩为正）：

`F_n = max(0, k_n * δ - c_n * v_n)`

其中 `δ` 是重叠量，`v_n` 是两球沿接触法向的**分离相对速度**（分离为正），`c_n = 2ζ√(k_n m_eff)`。球-墙接触取墙质量无限大的极限，球-球按两质量的约化质量计算。重力和接触力通过半隐式欧拉法积分。

在二维坐标平面描述颗粒位置、速度，但颗粒质量按球体体积乘以密度计算。这是教学演示模型，**不是已校准的二维岩土试样或真实三维砂石料仓**。

## 完整程序验证结果（本次运行）

单颗粒自由落体、无阻尼反弹、两球碰撞动量守恒、耗散作用、隔板单球法向支撑、移除后加速度，以及30颗粒隔板预沉降的平衡检查均通过。预沉降结束总动能约为 `3.48e-9 J`，隔板总支撑力与总重的相对误差约为 `4.18e-9`。

三种隔板高度的最大接触重叠分别为颗粒直径的 `1.60%`、`1.95%`、`2.26%`；保持低于这里设置的 `5%` 演示阈值。三组的总机械能在每次采样间均无正增量。

在 `0.15 m` 隔板工况，把时间步长从 `2e-5` 减到 `1e-5 s`，整个 `3.2 s` 计算中，归一化总机械能曲线最大差别为 `0.424%`、最终平均高度相差 `0.225%`、峰值动能相对差别约 `4.2e-8`。 **但严格动能阈值的“静止时间”分别为 `0.62 s` 与 `0.72 s`，这一指标仍有时间步长敏感性。** 因此不要将精确静止时刻作为经过收敛验证的定量结论。

## 输出文件

`results/shelf_release.gif`：3 组高度并排动画，隔板移除前有短暂静止展示；

`results/final_packing.png`：三组最终堆积对比；**其中水平虚线代表被移除隔板的原高度，不是真实存在的隔板**；

`results/energy_comparison.png`：三组动能与总机械能曲线；

`results/mean_height.png`：颗粒平均高度变化；

`results/summary.csv`：峰值动能、95%耗散时间、严格动能阈值时间、最大重叠量等；

`results/height_10cm_history.csv` 等：各个工况的完整采样历史数据；

`results/unit_checks.csv`、`preparation_checks.csv`、`numerical_checks.csv`、`time_step_diagnostics.csv`：基本物理、初始堆积、数值稳定和时间步长敏感性数据。
